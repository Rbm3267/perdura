PERDURA The Mind That Outlives Its Models Phase 0 · 2026-06-10

Perdura

A persistent knowledge graph that hires and fires LLMs based on what it has learned about them — spending money only where it disagrees with itself.

The Inversion

Conventional multi-agent systems treat agents as persistent and memory as incidental. Perdura inverts this: the memory is the system, and LLMs are interchangeable workers that board, contribute, and disembark.

The "mind" is a living knowledge graph — claims, evidence, open questions, decisions, and rejected paths, all typed, attributed, and confidence-scored. Because no working state ever lives inside a model, any model can be swapped mid-task with zero loss. The mind survives every model that ever powered it.

The graph is the system of record. Workers are stateless, commodity labor — swappable at any station because the state rides the train, not the worker.

Inverted Persistence

Claim 02

Epistemic Track Records

Every node is attributed. Over time the graph learns which models are reliable in which domains. The memory evaluates its workers.

Claim 03

Contention-Driven Economics

Cheap local models are the default labor force. Frontier and specialist models are summoned only when contradiction density rises.

Architecture

The memory is the line — continuous, persistent, always moving forward. Models are stations: the train stops, a worker boards with a bounded briefing, contributes a graph delta, and the train moves on without it.

The memory line never stops; workers do. Solid stations run today (Phase 1). The specialist station opens when the router ships (Phase 3) — its boarding trigger is contention, cost budgets, or domain-tag match.
Knowledge Graph

Typed nodes and edges; append-mostly. Nodes are superseded, never deleted, preserving the temporal record of how the mind changed. This is the living mind map.

Conductor

Deterministic code. Assembles bounded briefings, schema-validates incoming deltas, stamps attribution, merges, and recomputes contention. No LLM judgment in the merge path.

Workers

Any LLM behind a uniform interface. A worker sees a briefing and returns a strict JSON delta. It holds zero state worth preserving.

Router

Phase 3. A model registry with domain tags, cost, latency, and accumulated track records that matches open questions to workers and escalates when a subgraph disagrees with itself.

Retrieval Index

Phase 1.5. Nodes embedded via ChromaDB; briefings assembled by hybrid BM25 + dense search expanded through graph traversal.

Worker Lifecycle

Board

Briefing

Conductor selects the most-contended open question and assembles a bounded briefing.

Contribute

Delta

Strict JSON: new nodes, edges, supersedes, resolved questions. No prose.

Merge

Validate

Schema check, ID assignment, attribution, contention recompute. Bad deltas rejected.

Disembark

Release

Worker released. Nothing is lost — the graph survives without it.

Requirements

What the system must do, organized by phase and type.

Functional

FR-01
Persistent typed graph. Store nodes and edges with attribution, confidence, and timestamps; persist across sessions. P1 ✓
FR-02
Supersede, never delete. Stale nodes are marked superseded with a pointer to their replacement. P1 ✓
FR-03
Bounded briefings. Worker context from the question's 2-hop neighborhood under a fixed token budget. P1 ✓
FR-04
Strict delta contract. Workers return JSON-only deltas. The conductor schema-validates and rejects non-conforming output. P1 ✓
FR-05
Deterministic merge. No LLM judgment in the merge path — validation and contention recompute are pure code. P1 ✓
FR-06
Contention metric. Compute contradiction density per subgraph; prioritize which question is worked next. P1 ✓
FR-07
Anonymous briefings. Workers see content and confidence but never authorship — countering anchoring. P1 ✓
FR-08
Uniform worker interface. Any model participates through the same briefing-in / delta-out contract. P1 ✓
FR-10
Memoric binary. 96-bit epistemic encoding for hidden disagreement detection and track records. P0
FR-11
Track-record analytics. Per-model, per-domain reliability from node outcomes. P2
FR-12
Epistemic router. Contention- and budget-driven escalation; specialist summoning. P3

Non-Functional

NFR-01
Unbounded worker count. Cost and context per turn stay flat no matter how many models have served the graph.
NFR-02
Local-first. The full loop runs on a single machine with a local model and no cloud dependency.
NFR-03
Model-agnostic. Swapping a model requires zero changes to graph, conductor, or schema.
NFR-04
Auditable. Every node answers who said this, when, with what confidence, and what replaced it.
NFR-05
Resilient to bad workers. Malformed deltas are rejected without corrupting state; rejection becomes track-record signal.
NFR-06
Cost-proportional to disagreement. Steady-state spend trends toward local-model cost; frontier spend concentrates where contention is high.

Roadmap

How Perdura comes together in phases.

PHASE 0
Memoric Binary. 96-bit epistemic encoding with three validation experiments. Foundational research now.
PHASE 1
Graph + Workers. Knowledge graph, conductor, delta extraction, round-robin boarding, JSON persistence. Built and verified.
PHASE 1.5
Retrieval + Memoric. ChromaDB hybrid search, mind-map visualization, memoric binary integration into briefings.
PHASE 2
Track Records. Per-model, per-domain reliability from node outcomes. The memory learns which workers are trustworthy where.
PHASE 3
Epistemic Router. Contention-driven escalation, cost budgets, specialist summoning. The mind's hiring and firing mechanism.
